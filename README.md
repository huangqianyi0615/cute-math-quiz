# 星星数学大冒险

给 8 岁小朋友的加减法小测验，纯前端，不用后端、不用登录。

- 每次 16 道新题：温柔档（20 以内）、小星星档（100 以内两位数）、挑战档（三位数 + 缺数题）
- 大号虚拟数字键盘，也支持实体键盘
- 答对有星星，答错有图解（拆分、进位、退位都用图和短句讲）
- 结尾有星星、答对数、用时和错题图解复盘
- 横屏平板左右布局，竖屏手机上下布局

## 本地打开

直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000

## 部署

本仓库已开启 GitHub Pages，访问地址见仓库 Settings → Pages。
